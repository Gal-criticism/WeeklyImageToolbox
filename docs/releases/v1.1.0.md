# 周报图片采集工具箱 v1.1.0

Windows x64 便携版可从 [GitHub Releases](https://github.com/Gal-criticism/WeeklyImageToolbox/releases/tag/v1.1.0) 获取。解压后运行 `WeeklyImageToolbox.exe`，无需单独安装 Python。

v1.1.0 更新了任务存储、历史恢复和周边商品采集流程。自动采集与筛选结果仍需人工检查；本版本不承诺选图准确率。

## 主要更新

- **SQLite 任务存储与旧任务迁移**：新任务使用 SQLite 记录候选、进度、媒体状态和人工审核决定。迁移工具会检查旧任务并将媒体资产按内容哈希归档；迁移保留原始文件。v1 旧任务仍可打开和审核。
- **关闭行为更明确**：有任务运行时关闭窗口会先询问是否退出；确认后立即退出，不等待后台工作。没有任务运行时，关闭窗口直接退出。修复 Windows 在后台线程活动时偶发卡在退出阶段的问题。
- **按需导出未候选图片**：导出时可选择是否附带符合筛选条件的未候选备选图。
- **X 与 YouTube 媒体恢复**：历史任务可以继续处理已有记录的媒体，尽量复用已保存状态。恢复过程不会默认重新查询 SocialData。
- **周边商品补搜与商品级证据**：商品页下载后，只有未取得合格关联商品的高清原图时才继续补搜。候选保留商品关联、角色/参考图、原图状态及来源页面证据，供后续审核。
- **过滤 Amazon 推荐商品**：Amazon 商品详情页中的其他商品推荐不再作为当前周边商品候选。

## SocialData 与外部服务

SocialData 是可选服务，默认关闭。需要使用时，用户须自行配置密钥并在任务中明确启用；本发行版不包含任何付费凭据。公开页面是否可用取决于来源网站，商品关联和图片选择仍需人工复核。

## 旧任务与数据

v1 任务保留原有格式并保持兼容，可继续浏览和审核。需要切换到 SQLite 时，可在历史任务中选择“迁移任务存储”；迁移前建议备份整个任务目录。请保留任务目录中的数据库、资产、索引和最终导出文件。
