# 素材目录核对

工具箱在任务开始、恢复、审核载入、补图缺额判断和导出前后核对本地素材。核对会读取文件内容计算 SHA-256，分别统计原图、审核副本及成品；实际文件数不等于去重后的可用素材数。

手动加入且能明确关联到新闻的有效图片进入待复核，补图判断会复用这些图片。无法确定归属的文件保留在未归属记录中，原始来源标记为未知。删除文件不清除历史审核记录；同内容唯一移动可修正路径，同路径内容替换需要重新审核。

核对报告和清单保存在任务目录，记录时间、数量、路径、哈希及新增、删除、移动、替换情况。核对取消或读取失败时保留上一次完整清单，不能依据残缺扫描宣布素材不足。

导出会保留用户加入的文件。原程序导出路径被用户替换后，只有内容仍符合上次导出哈希的文件才由程序重新生成；遇到名称冲突时采用不覆盖的文件名。

本功能覆盖当前任务及本地历史素材，网盘通过设置中的“更新索引”单独刷新。
