# 多来源补图

新建任务中勾选“自动补图（从多个来源寻找缺图）”，设置目标张数（默认5），并选择来源。正常采集完成后，按官网、Steam、月幕公开图集、VNDB的顺序寻找补充候选。来源仍需人工核对；检索排名不能证明一个网站是官网。

目标张数用于决定是否继续查下一个来源，不限制当前图库只取五张。同作通用配图会单独标注；它不能自动充当某次活动或商品新闻的直接素材。

审核页中“往期周报”仍在第三栏，其后是“补图候选”。可补当前新闻、批量补不足项、继续补图、重试失败项或取消。新增候选先展示为备选；采用后才进入普通审核与导出。勾选导出未候选图片也不会导出未采用的自动补图候选。

每个任务单独保存已查链接。已解析、有图或无图的链接不会被常规继续操作重复访问；请求失败需要显式重试失败项。另一个新任务允许重新查同一链接。不同作品共用一个页面时复用页面结果，并重新核对作品归属。

直接素材和同作通用配图分别标注。作品名相似、文件名或宽高比不能证明图片属于该作品，FD、续作、重制版本需核对。所有图片的内容、UI、水印及成人画面仍需人工审核。保留原生版权小字，干净CG不采用对话框、菜单、转载水印和SAMPLE。

首版不调用模型，不自动下载视频。离线模式不进行网络补图。完整原件、来源页、原图地址、检索结果和审核状态保留在任务目录内；不要把“候选数量足够”理解为人工审核完成。

启动源代码版本可运行项目根目录的“启动工具箱.pyw”。独立试验版通过根目录的“00_启动工具箱-补图试验版.lnk”启动，程序位于dist/补图模块试验版-20261028/WeeklyImageToolbox。旧程序保留。
