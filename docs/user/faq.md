# 常见问题

## 便携版在哪里下载？需要安装 Python 吗？

Windows x64 v1.1.0 便携版从[GitHub Releases 最新版本](https://github.com/Gal-criticism/WeeklyImageToolbox/releases/latest)下载；[v1.1.0 发布说明](https://github.com/Gal-criticism/WeeklyImageToolbox/releases/tag/v1.1.0)。解压运行 `WeeklyImageToolbox.exe`，无需安装 Python。

## X 帖子有记录，但没有图片怎么办？

先在图片审核页检查对应新闻的“未候选／待复核”和“已排除”页签，查看失败状态、来源和原图按钮。X 来源的图片可能无法公开访问、已经失效，或需要你自行配置的 API 凭据。可在设置页填写自己的凭据；SocialData 需要在该轮新建任务时显式勾选，默认关闭。已记录的失败 X/YouTube 媒体可通过历史任务恢复，恢复使用已有记录，不会自动重新查询 SocialData。官网采集问题可使用“重试本条新闻”并填写官网地址。外部来源失效时无法保证补回图片。

## 提示缺少浏览器或 Playwright 怎么办？

浏览器是可选增强。若你需要动态网页采集，在项目环境中运行：

```powershell
python -m pip install -e ".[desktop,browser]"
python -m playwright install chromium
```

然后在“设置”页启用动态页面浏览器增强并点“检查浏览器”。若不需要动态网页增强，可保持该功能关闭，继续使用其他来源。

## 为什么“未候选／待复核”是空的？

可能是本轮没有可用图片、候选都已被标记为已选/排除，或备选筛选后没有符合条件的项目。导出备选要求图片可用、长边至少 800 像素、短边至少 600 像素，并且同一新闻内不能与已选/保留项像素确认重复。检查新闻过滤条件、其他审核页签和采集失败信息。原始资源及索引会保留，不会因未显示为备选而被清除。

## 导出目录出现 WinError 5 或“拒绝访问”怎么办？

这通常表示当前账户不能写入所选目录，或文件正被其他程序占用。关闭占用文件的程序，选择当前用户拥有写入权限的本地目录（例如用户文档下新建的文件夹），然后重试导出。不要把输出位置选为受保护的 Windows 系统目录、只读网络位置或正在同步且被锁定的文件夹。

## 如何更改输出目录？

新建任务页中可用“选择目录”更改本轮输出位置；设置页中的输出目录用于后续任务的默认位置。已有任务的目录在历史记录中保留，续跑时应选择该原任务。

## 停止后怎样续跑？

在进度页点“停止任务”后，打开历史任务，选择原任务并执行继续/恢复。保留原任务目录和原输入 DOCX，以便从已保存进度继续。单纯暂停时按“继续”即可；暂停会等待在途请求完成当前工作。

## 原始图片和索引在哪里？

任务结果目录保留 `raw`、索引、检查点、缓存及审核状态；`final/images` 是已选图片和通过筛选的未候选备选交付目录。`review_assets` 属于审核内部文件，不是备选目录。不要仅凭审核页是否显示来判断原始文件是否被删除。

## 最终图片目录里为什么可能有视频？

视频单独显示在“视频”页签，已选视频会随最终媒体导出到 `final/images` 的对应新闻目录，不会被转换成图片。只需要图片时，保持“跳过视频”选中；如需采集视频则取消勾选，并在播放或处理视频时检查 FFmpeg 是否可用。

## 可以只导出已选图片吗？

可以。在审核页取消“同时导出未候选图片”，再执行导出即可。默认可将符合筛选条件的未候选图片一并作为备选导出。

## 周边商品图如何筛选？

周边采集会查找商品详情并在未取得合格高清商品图时尝试补搜。候选会记录具体商品的关联、原图状态和商品页证据；图片仍需通过下载、尺寸和人工审核。Amazon 商品页会过滤其他商品推荐项。筛选结果需要人工确认，工具不承诺准确率。

## 命令行能选择栏目或启用 SocialData 吗？

当前 CLI 不提供这两个专用参数。使用桌面界面，在新建任务页选择 `x`（新作）、`h`（汉化）、`z`（周边）栏目，或按需启用 SocialData。
