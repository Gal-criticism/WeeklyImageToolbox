# 用户手册

## 名称与适用环境

Windows x64 便携版无需 Python，从[最新发布页](https://github.com/kasumi-ppp/galgame-news/releases/latest)下载 `WeeklyImageToolbox-v1.0.0-windows-x64.zip`，解压运行 `WeeklyImageToolbox.exe`。v1.0.0 发布页：[查看发布说明](https://github.com/kasumi-ppp/galgame-news/releases/tag/v1.0.0)。

在项目根目录安装：

```powershell
python -m pip install -e ".[desktop]"
```

启动桌面界面：

```powershell
python -c "from galgame_news.desktop.app import main; raise SystemExit(main())"
```

`desktop.app` 没有 `__main__` 执行入口，因此不要用 `python -m galgame_news.desktop.app` 启动。也可以双击项目中的 `启动工具箱.pyw`。

浏览器增强可选安装：

```powershell
python -m pip install -e ".[desktop,browser]"
python -m playwright install chromium
```

没有 Playwright/Chromium 时，常规采集仍可工作；动态网页增强功能则无法使用。该组件通过 GUI 设置页的浏览器状态检查和安装按钮管理。

## 新建任务

在“新建任务”页选择 `.docx` 周报并填写期号。选择一个可写的输出目录。输出目录应是你有写入权限的本地文件夹；设置页可指定默认输出目录，新任务页也可单独指定本轮目录。

### 栏目选择

GUI 提供三个栏目开关：

| 代码 | 界面名称 |
| --- | --- |
| `x` | 新作 |
| `h` | 汉化 |
| `z` | 周边（含业界及其他资讯） |

至少选择一个栏目。程序按周报识别到的原始顺序处理，并保留原编号，不会因为只选择一个栏目就将编号重新从 1 开始。命令行目前没有栏目选择开关。

### 视频与 X 媒体

“跳过视频”默认开启，适用于只需要图片的任务。取消后，工具可能发现并下载视频；视频会出现在“视频”页签中供审核、查看和播放，已选视频可导出到 `final/images` 的对应新闻目录，但不会转换成图片或进入图片备选。视频工具缺失时，可在“设置”页检查 FFmpeg。

设置中的 API 配置只保留“SocialData X 密钥”。输入遮蔽，已有内容不回填；留空保存会保留原值，更新成功后输入框清空。历史旧接口凭据保留，但不会被自动调用。

SocialData 为可选的 X 媒体查询服务，默认关闭。只有你自行拥有并填写密钥，且在“新建任务”中勾选“本次使用 X 图片与视频 API（SocialData）”，本轮才使用该服务。关闭时继续尝试公开页面采集。发行包不含任何私测凭据。不要把密钥粘贴到周报、文档或公开问题中。

设置页中填写自己的凭据并保存。凭据存入 Windows 凭据库，已有密钥不会回填到输入框；留空会保留已有值。界面可显示已配置/未配置状态。项目不提供可直接使用的密钥，也不承诺任何外部服务可用性。

## 进度、暂停与停止

进度页按新闻显示处理数量和异常事件。按“暂停”后，当前在途请求会先完成当前工作，随后暂停；再按“继续”恢复。暂停按钮不会删除任务结果。

“停止任务”用于结束当前运行。任务会保留已经写入的状态；可从历史任务列表选择该任务继续续跑。恢复时使用原任务目录和同一份输入周报。运行中关闭程序也可能中断工作，重新打开后可从历史任务恢复。

## 图片审核

### 界面布局

- 左栏：按新作、汉化、周边展开的新闻树；点击栏目查看该分区，点击具体新闻查看单条。
- 中栏：图片缩略图和页签，包含“已选”“未候选／待复核”“已排除”和“视频”。
- 右栏：大图预览、尺寸和来源信息、审核依据与操作按钮。

在同一新闻与页签中执行已选、排除或待复核操作后，缩略图列表保留滚动位置；切换新闻或页签不沿用上一列表的位置。查看当前项时，右侧支持放大、缩小和适应窗口。

### 审核快捷键

| 操作 | 快捷键 | 含义 |
| --- | --- | --- |
| 已选 | `A` | 标记为本期采用 |
| 排除 | `R` | 标记为不采用 |
| 待复核 | `P` | 留待稍后确认 |

点击项目后，可按住 `Ctrl` 逐项多选，或按住 `Shift` 选择连续范围。快捷键和按钮会应用于当前选中项。可以在右侧查看图片来源依据、新闻归属和技术详情；“打开来源”“打开官网”“打开原图”分别打开对应页面或记录中的原图媒体 URL，本地原件则保留在任务目录内。

### 未候选的筛选规则

未候选列表/导出备选会过滤低分辨率图片和同一新闻内已确认的重复画面。内容哈希或感知哈希加解码像素确认重复后，候选不会重复占据备选位置；仅凭旧的重复标记不会直接删除备选。尺寸已知的未候选图片须满足原始长边至少 800 像素、短边至少 600 像素。尺寸未知的失败记录不会仅因尺寸规则隐藏，但缺少可打开文件时无法导出图片。

这些筛选只影响审核展示和导出备选，不会删除原始下载文件、来源记录或索引。已选图片优先于未候选备选。

### 补充链接抓图

先选择一条具体新闻，在右侧“补充来源链接”中填写官网、VNDB、Steam 或 X 帖子链接，再点击“抓取补充图片”。新闻当前没有图片也可操作。官网会继续访问明确相关的图库或商品详情；不会重抓整份周报。

新图片默认进入“未候选／待复核”，由你决定是否采用；原先的人工选择保留。重复图与低分辨率图仍按上述规则过滤。补抓在后台执行，可取消，下载失败记录保留链接；再次填写同一链接可复用成功文件并恢复失败项。

补抓 X 沿用创建任务时的 SocialData 开关，默认关闭的任务不会自动付费查询。启用时同帖复用缓存和凭据库；补抓不下载视频。离线任务不能抓取补充网络链接。

补抓原件、审阅图和索引位于本任务 `retries` 批次目录，重新打开历史任务后仍可审核和导出。不要删除这些依赖文件。

### 导出内容与文件夹

点击“导出图片（含未候选）”生成最终图片交付。`final/images` 内含已选图片及通过筛选的未候选备选。请在审核页底部查看实际导出目录。

任务目录会保留原始下载资源、索引、检查点、缓存和审核状态，便于追溯和续跑。`review_assets` 是审核界面使用的内部资源，不代表全部可交付备选；用户应以 `final/images` 为准。

如果仅有 `final/images` 而没有任务索引，工具不能重建审核界面；可以直接打开该文件夹人工挑选图片。

## 命令行

命令行适合已有脚本或只需运行一次处理的场景：

```powershell
python -m galgame_news run "input/demo.docx" --issue demo --output "output/demo" --no-videos
```

参数如下：

| 参数 | 是否必填 | 用途 |
| --- | --- | --- |
| `input` | 是 | DOCX 输入文件路径，写在 `run` 后 |
| `--issue` | 是 | 本期期号 |
| `--output` | 否，但建议始终填写 | 显式指定输出目录，避免使用源码中的开发环境默认路径 |
| `--offline` | 否 | 使用离线模式 |
| `--no-videos` | 否 | 关闭视频发现和下载 |
| `--config` | 否 | 指定配置文件路径 |
| `--history-db` | 否 | 指定历史数据库路径 |
| `--llm-provider` | 否 | 指定 LLM 提供方 |
| `--llm-model` | 否 | 指定 LLM 模型 |
| `--max-images` | 否 | 限制图片数量 |

命令行没有栏目选择或 SocialData 专用参数，这两项在 GUI 中设置。CLI 参数可用 `python -m galgame_news run --help` 查看。
