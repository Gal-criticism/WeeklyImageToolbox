# 往期周报素材检索

此模块把本地历史任务和 Nextcloud 往期目录中的素材提供为本期备选。每条新闻检索该作品在本期之前最近出现的两期周报，并列出这两期中该作品／新闻目录匹配的全部图片和视频；只有一期匹配时展示该一期，不混入无关作品。勾选“无视频”时会过滤视频，不会为补视频继续翻找第三期。检索只读取素材元数据，不自动下载或采用；用户选择预览、查看原图或采用时才按需读取所选文件。没有采用的备选不会被导出。

## 配置与建立索引

1. 打开“设置 → 往期周报素材”，填写服务器地址、账号（支持用户ID或邮箱）、往期目录路径；使用应用密码。服务器只填源站地址，例如 `https://cloud.example.com`，根目录填网盘中的路径，例如 `/往期周报`。
2. 密码留空保留已存凭据。密码进入系统凭据库，不写入普通设置、任务索引或日志。测试连接前输入的密码也会先保存到凭据库。
3. 本地来源包含已登记的历史任务，可额外填写历史任务根目录；不扫描整块磁盘。支持标准JSON输出和工具箱的SQLite任务。
4. 点击“测试连接”，然后“建立／更新索引”。只索引目录和文件元数据，不批量下载图片、视频原件；新建任务中的时间范围决定查询时使用哪些记录。日期缺失或存疑的记录保留提示，不用文件修改时间替代周报日期。
5. 日后手动更新索引。更新失败保留上一次可用的索引；不会为了检索自动重新抓取所有往期。

目录也支持图片组常见的 `223周边`、`223新作`、`2026.2.21 231期新作` 等命名。日期从明确的路径日期读取；无法确认的日期仍标记待核。配置的共享根下若直接有期次目录，会只索引这些期次分支，跳过同级解包或活动素材目录；如周报存放在其他嵌套容器内，应将根目录指向相应容器。

目录也支持图片组常见的 `223周边`、`223新作`、`2026.2.21 231期新作` 等命名。日期从明确的路径日期读取；无法确认的日期仍标记待核。配置的共享根下若直接有期次目录，会只索引这些期次分支，跳过同级解包或活动素材目录；如周报存放在其他嵌套容器内，应将根目录指向相应容器。

## 本次任务启用

在“新建任务 → 抓取选项”勾选“往期周报素材检索”，其下方才会显示“检索范围”：默认“最近一年”，也可选择“全部周报”。前者按最近365天过滤可靠日期，后者不限制日期；两种范围都只返回作品最近出现的两期，不是返回全部期次。范围随任务保存，恢复任务时沿用；旧任务没有范围字段时按“最近一年”。取消勾选后隐藏范围选项。功能默认不勾选，旧任务缺少启用选项时也按关闭处理。

需要历史视频时，取消“跳过视频，仅抓取图片”；该选项对本次正常采集和历史素材同时生效。离线模式仅检索本地索引、使用本地或已缓存原件，不连接网盘。

## 审核与采用

中间素材区的标签顺序为：

**已选｜未候选／待复核｜往期周报｜已排除｜视频**

1. 左侧选择具体新闻，再打开第三个“往期周报”标签。没有作品名时可修改检索关键词。
2. 卡片显示历史期号、标题、来源、大小和版本提示。点击卡片先获取缩略图，右侧显示预览与来源；服务器没有缩略图时显示占位信息，不偷偷下载整份原件。
3. 明确点击“预览／打开原图／播放视频”时，才按需缓存这一个原件。视频封面与可播放原视频分开处理。
4. 确认适合本期后点击“采用”。图片经过下载/本地导入、解码、真实格式转换与去重，视频经过媒体验证，再加入本期审核。图片进入“已选”；视频在“视频”标签中保留已选决定。
5. 重复采用不会重复添加。同一文件被不同新闻复用时，共享缓存，但各条新闻的采用与审核决定独立。

往期图片不自动认定为干净CG，历史视频也不自动认定为官方OP。请根据本期要求复核。明确不同版本的记录不会自动匹配；仍不确定的版本会保留待核提示。

**“同时导出未候选图片”不会导出尚未采用的往期备选。** 只有明确采用并通过文件处理的素材才进入普通审核与导出流程。

## 保存与追溯

- 索引是独立的可重建数据库，位于应用数据目录下 `archive/index.sqlite3`；不会改写原周报或原任务选择。
- 当前任务的历史结果有独立快照，索引更新后可重新查询；重新载入任务时保留已采用素材与审核状态。
- 采用记录保留历史期号、归档路径、原始来源和哈希。导出清单中的 `archive_assets` 对应实际导出文件，便于离开工具箱后仍能追溯。
- 文件失效、认证失败、取消或达到大小/时长/分辨率限制时显示具体状态，不把失败原件当已采用，不影响既有素材。

## 当前验证范围

自动测试使用冻结的Nextcloud元数据与媒体夹具、本地JSON/SQLite历史任务，以及项目 `input/` 中22份真实DOCX。22份文件当前解析出500条新闻记录；这是本地解析观察值，不是采集准确率，也不代表已下载500条新闻的图片。

测试不调用付费API或批量连接网盘。真实网盘需要在设置中提供有效凭据后执行“测试连接”及少量定点采用验收；离线测试通过不能替代这一步。
